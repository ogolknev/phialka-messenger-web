# Phialka Messenger

A self-hosted messenger built around shareable plugins.

## Status

⚠️ **Early Development Stage**

The project is under active development. Many features are incomplete,
and the API may change without notice.

## Core Concept

Plugin system that allows users to share custom features with their contacts.
If someone sends content created by a plugin, the recipient can install it
to view and interact with that content.

## Tech Stack

- **Frontend:** Vue 3 + TypeScript + Vite
- **Backend:** Bun + Hono
- **Database:** PostgreSQL
- **Realtime:** WebSocket

## Development

```bash
pnpm install
pnpm dev
```
